# YouTube X

YouTube'u X (Twitter) gibi gösteren Chrome eklentisi.

- X'in düzeni, YouTube'un koyu renk paleti (kırmızı vurgular)
- X tarzı sol menü, "Sana özel / Takip edilenler" sekmeleri, "Neler oluyor?!" kutusu (YouTube'da arar)
- Reklam, Premium ve promosyon kutuları gizli
- Videolar gönderi kartı olarak tek sütunlu zaman akışında (yanıtla, yeniden gönder, beğen, görüntüleme, paylaş)
- Sağda arama, "Neler oluyor" (akıştaki gerçek konular), "Takip ettiklerin" ve "Kimi takip etmeli"
- İzleme sayfasında menü daralır, video büyür; "Sıradaki" listesi, yorumlar yanıtlar gibi
- Keşfet sayfası, eklenti simgesinden aç/kapat

## Kurulum

1. Chrome'da `chrome://extensions` adresini aç
2. Sağ üstten **Geliştirici modu**nu aç
3. **Paketlenmemiş öğe yükle** → bu `youtube-x` klasörünü seç
4. https://www.youtube.com adresini aç (açıksa yenile)
